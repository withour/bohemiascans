🎙 Hlasová hesla


V souvislém režimu se text ukazuje rovnou v políčku. Diktujte dál bez čekání; další políčko určíte heslem, například „jméno Jan Novák začátek sedm příjezd osm“. Text se průběžně upřesňuje. Pro volný text klikněte do políčka; další údaj zahajte heslem nebo „další políčko“. Vypnutím souvislého režimu obnovíte automatický posun po dokončené větě.

Hesla „zakázka“, „vedoucí“, „poznámka“, „další poznámka“, „lidé“, „jméno“, „začátek“, „příjezd“, „oběd“, „konec“, „materiál“, „jednotka“, „množství“ „datum“, „počasí“ a „další řádek“ jsou příkazy a do buněk se nezapisují. Přechod určete slovy „další políčko“ nebo „další poznámka“. U materiálu nejprve určete „materiál“, potom „množství deset kilogramů“. Jednotka se doplní sama. Po potvrzení množství se diktování přesune na název materiálu v dalším řádku. Neplatné množství nepřepíše již vyplněné hodnoty. Do tisku a uložení vstupují potvrzené údaje; průběžný náhled se ještě může změnit.

Přepis diktování

Obecné:
"zakázka [text]" → zakázka
"vedoucí [jméno]" → vedoucí
"poznámka [text]" → první volný řádek poznámek
"další poznámka [text]" → další řádek poznámky

Lidé (záložka 2):
"lidé" → otevře prázdný řádek
"další osoba" → další prázdný řádek
"jméno [jméno]" → nová osoba
"[jméno osoby]" → vyvolá osobu
"začátek [čas]" → začátek práce
"příjezd [čas]" → aktivní osoba; bez vyvolané osoby příjezd vozidla
Po „lidé [jméno]“ lze diktovat časy postupně: začátek, příjezd, oběd, konec. Pro souvislou řeč můžete použít hesla před časy, například „začátek sedm příjezd osm“.
"oběd [čas-čas]" → oběd
"konec [čas]" → konec práce
"kilometry [číslo]" → km osobní vůz
"příspěvek [číslo]" → příspěvek km
"vozidlo [typ]" nebo "auto [typ]" → vozidlo
"příjezd vozidla [čas]" → příjezd vozidla
"odjezd [čas]" → odjezd vozidla
"počet km [číslo]" → km celkem
"vozík [ano/ne]" → vozík
"počasí [popis]" → počasí
"datum [datum]" → datum; do Checklistu a Materiálu se přebírá automaticky

Materiál (záložka 3):
"materiál [název]" → nový řádek materiálu
Jednotka je pro ruční psaní zamčená; vyplní se z množství nebo hlasovým heslem.
"jednotka [název nebo zkratka]" → např. „kilogramů“ zapíše kg
"množství [číslo a jednotka]" → např. „10 kilo“ zapíše 10 a kg
"další řádek" → přejde na další řádek

Pracovní činnosti (záložka 4):
"práce [popis]" nebo "činnost [popis]" → nová práce
"výkon [hodnota]" → výkon
"jméno [jméno]" → jméno pracovníka
"další řádek" → přejde na další řádek
